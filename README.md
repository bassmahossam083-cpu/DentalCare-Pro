# DentalCare Pro V9

نسخة تجريبية متكاملة لموقع وواجهة إدارة عيادة أسنان، تشمل:

- واجهة تسويقية بالأبيض والأخضر
- صورة الطبيب في الواجهة الرئيسية
- معرض حالات الابتسامة وصورة حالة تقويم
- حجز مواعيد متصل بلوحة الإدارة
- إدارة المرضى، الخطط العلاجية، ومخطط الأسنان
- المحاسبة والفواتير لصلاحية الاستقبال
- مساعد ذكاء اصطناعي:
  - **Generative mode** عند ضبط `OPENAI_API_KEY`
  - **Fallback mode** عند عدم توفر المفتاح

## التشغيل

```bash
npm install
npm start
```

ثم افتح:

- الموقع: `http://localhost:3000`
- لوحة الإدارة: `http://localhost:3000/admin.html`

## ملاحظات

- البيانات الحالية تجريبية فقط.
- لا يُستخدم هذا المشروع لتخزين بيانات مرضى حقيقية دون ضوابط أمنية وقانونية مناسبة.
- يمكن استبدال الصور الموجودة داخل `public/assets` بصور العيادة الفعلية.
